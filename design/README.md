# Dicey! visual explorations

**Selected direction: C — Arcade Night.** The owner chose its retro neon
energy and expressive avatars.

These are concept boards, not production assets or
functional screenshots. All were created using the built-in imagegen tool.

| Option | Direction | Main ingredients |
| --- | --- | --- |
| A — Pocket party | Original light concept | Warm cream, coral, sunshine, friendly toy-like creatures |
| B — Midnight party | Dark counterpart to A | Midnight indigo, plum surfaces, ivory dice, coral/yellow accents |
| C — Arcade night | Alternative dark identity | Blue-black, electric mint, hot pink, bolder sticker-like characters |

C is the reference for future artwork and interface implementation. A and B
are retained as exploration history; they are not the active theme direction.

Review the wordmark, creature expressions, palette, and level of visual energy
separately. The final interface needs a complete scrolling scorecard, accessible
contrast, consistent dice faces, and real text/controls. Concept sample rolls and
score previews are illustrative; game rules remain defined by the engine.

Files:

- `dicey-concept-v1.png`: A, original light board.
- `dicey-midnight-v1.png`: B, dark theme exploration.
- `dicey-arcade-v1.png`: C, selected visual direction.
- `CONCEPT-PROMPT.txt`: original generation prompt.
- `MIDNIGHT-PROMPT.txt` and `ARCADE-PROMPT.txt`: dark exploration prompts.

See `docs/BRAND.md` for the selected direction and production guidance.
